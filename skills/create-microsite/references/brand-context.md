# Swing agency context

Swing is a fictional premium, trendy golf lifestyle brand for girls, selling apparel and frequent limited capsule collaborations. Its lifestyle/retail references are Malbon (https://malbon.com/) and Fore All (https://www.foreall.com/). These are references for ethos, not permission to reuse their copy, logos or media.

Swing has few internal technical staff and outsources most web development. Codex is the expert agency delivering visually accomplished campaign experiences and a reliable review/release process that Marketing can use without operating developer tools.

Campaign microsites are standalone, single static marketing pages: immersive digital magazines with photography, video and a story about a collaboration, collection or sale. The fictional parent is wearswing.com; campaign routes may look like `/campaign/johnmontgomery/`. Do not build the parent site or product pages. Avoid parent navigation/header/footer clutter. Product photography may later link to verified parent product URLs, but pages/destinations must not be invented.

Stay aligned with parent-brand language and the supplied campaign direction. Source only approved content/assets. Preserve factual product copy and media provenance. The user’s explicit campaign edits supersede an earlier brief’s coverage/layout constraints; record the approved change so the checks match it.

The Sunday Edit established a useful visual preference: varied, close-knit photo/video collages, occasional white-bordered scrapbook overlaps, few small captions, and limited repeated headings. Treat this as inspiration when compatible with a new brief, not a mandatory template. Its final reduced media selection and visible third-party marks were explicitly approved for that campaign only.

For ambient video: muted inline playback, visible controls, pause offscreen/hidden tabs, respect manual pause and reduced motion, and retain useful poster/error fallbacks. Do not download stock/generated content or fonts just to fill a gap. Ask for missing required source material.

The current Vercel project is https://vercel.com/ownward/swing-microsites and the code repository is https://github.com/fernando-espinoza/swing-microsites. Verify live configuration from repository deployment docs and the provider before acting; a URL in this reference is not proof that production routing is connected to wearswing.com.
