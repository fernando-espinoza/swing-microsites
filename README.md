# Swing — The Sunday Edit

Standalone editorial campaign for **Swing × John Montgomery**. Static HTML/CSS, a small native-film enhancement, all 30 supplied photographs, and the three approved product records. No backend, runtime third-party requests, or commerce integration.

## Local preview

Use the Node 24 version in `.nvmrc`, then:

```sh
npm ci
npm run build
npm run preview
```

Open **http://127.0.0.1:4173/campaign/johnmontgomery/**. The root URL is intentionally not a parent-brand website.

The approved original assets and film derivatives must be present in ignored `assets-source/sunday-edit/`. They are already staged in this implementation worktree. A fresh checkout needs the authenticated campaign assets described in the [handoff](docs/sunday-edit/handoff.md); private source media is not embedded in Git history.

## Verify

```sh
npx playwright install chromium firefox webkit
npm run check
```

`npm run check` runs source/content policy tests, static build, HTML/resource audit, and Chromium/Firefox/WebKit tests. [QA results and remaining release checks](docs/sunday-edit/qa.md).

## Edit and deliver

- `content/sunday-edit/`: reviewed campaign copy, exact product details, asset provenance, image layout, and approval records.
- `src/render/`, `src/styles/`, `src/client/`: static presentation and the native-film enhancement.
- `dist/campaign/johnmontgomery/`: self-contained public artifact generated by the build.
- [Hosting, source assets, safe updates, and rollback](docs/sunday-edit/handoff.md).

Product URLs deliberately remain null. Fonts currently use the approved planning fallback of locally available system faces; production type sign-off awaits licensed font files or explicit fallback approval. The website has not been deployed.
